# Anchor Nishi Rawat — Official Portfolio Website

> **"Where Every Moment Becomes a Memory."**  
> Luxury personal portfolio website for **Anchor Nishi Rawat** — Premier Anchor, Emcee & Voice Artist based in Bhopal, India. Specializing in luxury weddings, corporate conclaves, national summits, and signature cultural galas.

---

## 🌟 Overview

An extraordinary, cinematic, animation-rich personal brand portfolio crafted with:
- **Cinematic Preloader & Spotlight Reveal**
- **Hero Slider** with dynamic stage imagery and luxury typography
- **About Section** celebrating Nishi's mic presence and journalistic foundation
- **Horizontal 3D Milestone Timeline** tracking her journey from age 18 to national platforms
- **Service Experience Suites** for Luxury Weddings, Corporate Summits, and Celebrations
- **Signature Editorial Portfolio & High-Speed Media Lightbox**
- **4 Curated Live Stage Video Showreels**
- **Highlighted Stage Moments Marquee Slider**
- **Direct VIP Booking Enquiry Suite & WhatsApp Integration**

---

## 🛠️ Tech Stack

- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS + Custom Luxury Theme Palettes (Deep Charcoal `#101014`, Rich Black `#08080B`, Burgundy `#641C32`, Champagne Gold `#D6B779`)
- **Typography:** Cormorant Garamond, Playfair Display, Inter, Manrope, Pinyon Script
- **Icons:** Lucide React
- **Hosting:** GitHub Pages

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/Megharaikwar139/anchor-nishi-rawat.git

# Navigate to project directory
cd anchor-nishi-rawat

# Install dependencies
npm install

# Start local development server
npm run dev
```

---

## 📦 Production Build

```bash
# Build for production
npm run build
```
